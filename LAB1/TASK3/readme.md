## 基本栈操作指令

- `PUSH`：`PUSH direct` 栈顶指针 $SP$ 加 1，然后将地址上存的数据压入栈中。
- `POP`：`POP direct` 将栈顶的数据弹出，$SP$ 减 1，具体地，8051的弹出是将栈顶元素弹出，写入到指定地址 `direct` 中。

补充一点，如果想要实现像高级语言那样 `u=st.top()` 只查询不弹出的操作，可以这样写：

```assembly
MOV A, SP
MOV R0, A
MOV A, @R0
```

上述代码就是先将栈顶指针 $SP$ 的值存入 $A$ 中，然后通过 `@R0` 将 $SP$ 指向的地址上的数据存入 $A$ 中。

> 为什么8051要这样设计？由于8位单片机、精简指令集、没有复杂的寄存器调度，那么只能将所有数据流动必须明确指定目的地
