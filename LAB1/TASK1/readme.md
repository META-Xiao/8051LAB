**实验内容**：编写汇编片段，将数据从一个地方转移到另一个地方。

1. **直接寻址**：将 $40H$ 单元的内容传送到 $R0$。
2. **间接寻址**：利用 $R1$ 作为指针，将内部 RAM $50H$ 地址的内容取出送入 $A$。
3. **位寻址**：将 $20H.3$ 位（位地址 $03H$）的值取反送入 $P1.0$

## 基础知识

单片机的存储空间分为：

- 寄存器
    - `00H~1FH` 一共三组寄存器（R0~R7），比如第零组R0~R7的地址是 `00H~07H` ，每个8 byte（字节，B=8b 8比特位）
    - `80H~FFH` SFR（特殊功能寄存器），有  

| 名字 | 功能 | 地址 |
| --- | --- | --- |
| A | 累加器 | E0H |
| B | 乘除用 | F0H | 
| PSW | 程序状态字 | D0H |
| SP | 堆栈指针 | 81H |
| DPTR | 数据指针 | 82H/83H |
| P0~P3 | IO口 | 80H 90H  A0H B0H |
| TMOD | 定时器模式 | 89H |
| TCON | 定时器控制 | 88H |

- 内部RAM
    - `50H~7FH` 128 byte
- 外部RAM
    - `0000H~FFFFH` 64K byte

> 这里说明下单片机中内部RAM相当于一个数组，数组内部某个元素的大小为 1B (即 8bit) ，其数组下标就是地址，比如对于地址 `50H` 的内容，可以通过 `MOV` 指令将其内容传送到 `R0` 中，即 `MOV R0, 50H` 类比C就是 `R0=RAM[0x50]` ，~~来访问？~~ 严格意义上就是移动。

## 基本汇编命令

- `MOV` 指令：将数据从一个地方转移到另一个地方，具体就是 `MOV {$A}, {$B}` 将 `$B` 的内容传送到 `$A` 中， 如：
    - `MOV R1, 40H` 将片内RAM地址 `40H` 的内容传送到 `R1` 中
    - `MOV A, R1` 将寄存器 `R1` 的内容传送到 `A` 中， **这条命令只能在寄存器之间使用**
    - `MOV A, @R0` 将寄存器 `R0` 中存储的地址指向的内容（@为指针）传送到 `A` 中
    - `MOV 40H, #4FH` 将立即数（实际上就是存储的值 8bit） `4FH` 传送到地址 `40H` 中
    - `MOV TMOD, A` 将寄存器 `A` 的内容传送到 `TMOD` 中
    - `MOV C, P1.0` 将寄存器 `R1` 的第0位（最低位）的值传送到 `C` 中， **位操作只能和C（进位）寄存器搭配**
- `MOVC` 指令：将数据从程序存储器（ROM）中取出，传送到累加器 `A` 中，具体就是 `MOVC A, {$A}` 将 `$A` 的内容传送到 `A` 中，用于查表（常考！）， 如：
    - `MOVC A, @DPTR` 将数据指针 `DPTR` 中存储的地址指向的内容传送到 `A` 中
- `MOVX` 指令：将数据从外部存储器中取出，同上。

## 实验代码

```assembly
MOV R0, 40H ; MOV Rn Adress 
MOV R1, #50H; MOV Rn Value , Val is Adress
MOV A, @R1; pointer 
MOV C, 03H; C=20H.3
CPL C; C~=C
MOV P1.0 C; 
```

编译后 `MOV A, 40H` 和 `MOV A, #40H` 都是占两字节，操作和地址分别占一字节。
